# Menu da guia, divisões e grupos

[English](../../en/features/tab-groups.md)

Estes recursos funcionam na lista de guias vertical (barra lateral).

## Menu da guia

Clique com o botão direito em uma guia, ou na parte vazia da lista, para abrir o menu do próprio Spark em vez do menu do navegador:

- **Nova guia** e **Reabrir guia fechada** (aparece só quando há uma guia fechada para reabrir).
- **Adicionar guia aos favoritos** (só páginas da web; na parte vazia da lista vale para a guia ativa).
- **Adicionar divisão abaixo** e as ações de grupo descritas abaixo.
- **Mover para a janela…** (em uma guia).

## Divisões

Uma divisão é uma linha, com nome opcional, que separa grupos de guias.

- Crie com **Adicionar divisão abaixo**; o campo de nome abre na hora. Enter salva e Escape cancela.
- Arraste a divisão para cima ou para baixo para movê-la; as guias deslizam para dar lugar.
- Dê um duplo clique, ou clique com o botão direito e escolha **Renomear divisão**, para mudar o nome. Botão direito → **Remover divisão** apaga.
- Ao fechar a guia logo acima de uma divisão, a divisão passa para baixo da guia anterior que permaneceu aberta no mesmo espaço de trabalho e janela. Se não restar nenhuma guia acima, a divisão vai para o topo da lista.

## Grupos

Um grupo é um conjunto de guias com nome e cor.

- **Criar:** botão direito em uma guia → **Criar grupo com esta guia**. Com várias guias selecionadas (Ctrl ou Shift + clique), o menu mostra **Criar grupo com N guias** e usa todas. O campo de nome abre na hora.
- **Adicionar guias:** arraste uma guia (ou toda a seleção) para o cabeçalho de um grupo ou para uma das guias dele, ou use **Adicionar ao grupo: …** no menu da guia.
- **Sair de um grupo:** **Tirar do grupo** no menu da guia, ou arraste a guia para uma guia que não está em grupo.
- **Menu do cabeçalho (botão direito no cabeçalho):** renomear, mudar a cor (oito cores), escolher como o grupo abre ou **Desagrupar**. Um grupo sem guias some.
- **Como o grupo abre (por grupo):**
  - *Recolher e expandir no lugar* (padrão): clique no cabeçalho para recolher ou expandir. A guia ativa continua visível com o grupo recolhido.
  - *Abrir guias em uma lista ao lado*: clique no cabeçalho e as guias do grupo aparecem em uma lista ao lado; escolha uma para ir até ela.

As guias de um grupo aparecem sempre juntas, abaixo do cabeçalho, no lugar da primeira guia do grupo.

## Armazenamento

Divisões e grupos ficam salvos no banco de dados do app neste dispositivo, então sobrevivem ao reiniciar. Não entram nos backups. Guias efêmeras (privadas) não são salvas com a sessão, então suas divisões e grupos também não voltam.
