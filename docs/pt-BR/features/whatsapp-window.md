# Popover do WhatsApp

A barra de título tem um botão monocromático do WhatsApp, disponível no Windows nesta versão. Ele abre o WhatsApp Web dentro da janela do navegador. Escolha o formato em **Configurações → Aparência e disposição → Exibição do WhatsApp**; a opção fica salva após reiniciar.

## Comportamento

* **Popover compacto** é o formato padrão. Ele abre abaixo do botão, alinhado à direita quando possível, com até 560 × 680 pixels CSS e se reduz para caber na janela do navegador.
* **Painel lateral** abre abaixo da barra de título, junto à borda direita. A página, inclusive painéis divididos, é redimensionada para abrir espaço e volta ao tamanho anterior quando o painel fecha.
* Clique no botão para mostrar ou ocultar o WhatsApp.
* Leia o QR code uma vez. O login fica no perfil padrão do navegador e continua após reiniciar.
* Ocultar o popover mantém a conexão e as notificações ativas.
* O popover não aparece nas abas, no histórico nem nas sessões salvas, e não pode executar comandos do navegador.
* Links que tentam abrir novas janelas são bloqueados.

## Limites

* Clicar em outra parte do navegador ainda não oculta o WhatsApp; use o botão.
* Disponível apenas no Windows. Nos outros sistemas o botão fica oculto.
* O WhatsApp Web exige um celular com o WhatsApp vinculado à conta.
