# Site search shortcuts

Open **Settings → Search & Navigation → Site search shortcuts** to add a name, keyword and HTTP/HTTPS search URL containing one `{query}` marker in its path or query. The initial list is empty. Keywords contain 1–24 ASCII letters, digits, underscores or hyphens and are unique without regard to case.

Type `keyword search terms` in the address bar or either Command Bar navigation action. Terms are encoded once; unknown keywords use the default search engine. Edit and remove shortcuts in settings. Native navigation and tab creation share the same resolver and SQLite records. The browser preview uses validated local preference storage and the same search behavior.
