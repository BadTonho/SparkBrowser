# Tab menu, dividers and groups

[Português](../../pt-BR/features/tab-groups.md)

These tools work in the vertical tab list (sidebar).

## Tab menu

Right-click a tab, or the empty part of the tab list, to open Spark's own menu instead of the browser's:

- **New tab** and **Reopen closed tab** (shown only when there is a closed tab to reopen).
- **Add tab to bookmarks** (web pages only; on the empty part of the list it applies to the active tab).
- **Add divider below**, and the group actions described below.
- **Move to window…** (on a tab).

## Dividers

A divider is a line, with an optional name, that separates groups of tabs.

- Add one with **Add divider below**; the name field opens right away. Press Enter to save or Escape to cancel.
- Drag a divider up or down to move it; the tabs slide out of the way.
- Double-click it, or right-click it and choose **Rename divider**, to change the name. Right-click → **Remove divider** deletes it.
- A divider sits below one tab. If you close that tab with its **✕** button the divider moves to the tab above it.

## Groups

A group is a named, colored set of tabs.

- **Create:** right-click a tab → **Create group with this tab**. With several tabs selected (Ctrl or Shift click), the menu reads **Create group with N tabs** and uses all of them. The name field opens right away.
- **Add tabs:** drag a tab (or the whole selection) onto a group header or onto one of its tabs, or use **Add to group: …** in the tab menu.
- **Leave a group:** **Remove from group** in the tab menu, or drag the tab onto a tab that is not in a group.
- **Header menu (right-click the header):** rename, change the color (eight colors), choose how the group opens, or **Ungroup**. A group with no tabs left disappears.
- **How a group opens (per group):**
  - *Collapse and expand in place* (default): click the header to fold or unfold the group. The active tab stays visible while the group is folded.
  - *Open tabs in a side list*: click the header and the group's tabs appear in a list next to it; choose one to switch to it.

The tabs of a group are always shown together, below the header, where the group's first tab is.

## Storage

Dividers and groups are saved in the app database on this device, so they survive restarts. They are not included in backups. Tabs in ephemeral (private) mode are not saved with the session, so their dividers and groups do not come back either.
